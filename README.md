# CiviWise - Smart Civil Engineering Platform for Sri Lanka

CiviWise is a comprehensive web platform designed specifically for civil engineers in Sri Lanka. The application provides a suite of tools to assist with various aspects of civil engineering projects, from site analysis to design recommendations, climate data exploration, code reference, and geographic information visualization.

## Features

### Site Feasibility Analyzer
- Interactive map for location selection
- Region-based site data analysis
- Elevation, rainfall, and soil type information
- Risk assessment for floods, landslides, and erosion
- Climate Smart Score with recommendations

### Civil Design Assistant
- Project type selection (building, bridge, retaining wall, etc.)
- Site condition inputs
- Comprehensive recommendations for foundation design, drainage systems, and slope stability
- Export options to PDF and AutoCAD (DXF)

### Climate Explorer
- Location-based climate data
- Monthly rainfall pattern visualization
- Temperature trend analysis
- Extreme weather event tracking
- Climate trend analysis with regression lines

### Code Helper
- Searchable database of building codes and regulations
- Filtering by authority (ICTAD, NBRO, UDA, etc.)
- Filtering by category (building, structural, geotechnical, etc.)
- AI chatbot for code-related queries

### Map Dashboard
- Interactive map with multiple data layers
- Construction project visualization
- Natural resource locations
- Geological hazard mapping
- Critical infrastructure display

## Recent Enhancements

### Climate Smart Score
The Climate Smart Score feature gamifies climate-conscious design by providing scores, badges, and recommendations. This encourages civil engineers to consider climate factors in their designs, leading to more resilient and sustainable infrastructure in Sri Lanka.

### Multilingual Support (In Progress)
We're working on adding Sinhala and Tamil language support to make the platform more inclusive, especially for government officials and engineers in rural areas who may prefer working in local languages.

## Technologies Used

- **Frontend**: Next.js, React, Tailwind CSS
- **Maps**: Leaflet
- **Data Visualization**: Chart.js
- **API**: Server-side API routes

## Getting Started

```bash
# Clone the repository
git clone https://github.com/HasalYapa/civiwise.git

# Navigate to the project directory
cd civiwise

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
